# Daily Calorie & Routine Coach — Android APK Starter

## Option A: Build an APK locally with Capacitor & Android Studio
1. Install Node.js and Android Studio on your computer.
2. Open a terminal in this folder and run:
   npm install
   npx cap add android
   npx cap open android
3. In Android Studio, select **Build > Build Bundle(s) / APK(s) > Build APK(s)**.

## Option B: Generate an APK online with PWABuilder (no Android Studio)
1. Upload the `www/` folder to Netlify Drop, Vercel, or GitHub Pages.
2. Paste your live `https://` URL into https://www.pwabuilder.com/.
3. Choose **Android** and download your APK package.
